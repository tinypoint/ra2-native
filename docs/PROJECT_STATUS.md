## 本阶段验证

v0.1.10 验证了原生分辨率确认弹窗绘制、取消、两次确认与返回菜单。v0.1.11 在最终优化 Wasm 上，用 Chrome 触摸事件检查了 640×480、800×600、1024×768 三档地图列表的滚动条位置与向下滚动。公开页面、清单、程序分块哈希均已核验。详情见 WEB_RESOLUTION_FIX.md；桌面触摸模拟不替代实体 iPhone 稳定性验证。

## 保留的问题

1. iPhone Safari 偶发卡住或页面重载。用户最新两份诊断没有捕获具体异常；一份在切回前台后持续 FPS 0，另一份在改为 640×480 后掉帧并重载。记录的 Wasm 内存为 521,338,880 字节，不代表浏览器进程总内存，不能据此确认内存不足。尚未完成根因定位或修复。
2. 高分辨率启动图周围存在内部黑边，而 640×480 截图铺满游戏画布。尚未对照原版确认是原始布局还是移植绘制行为，不能归因为原版游戏缺陷。网页 contain 与画布内部绘制需要分别检查。
3. YR、战役和长期稳定性仍未完成全量验证，当前交付不表示全部内容已验证。
